# Pipoca no Balde 🍿

Primeira base de interface mobile-first para cardápio digital.

## Executar
Abra `index.html` no navegador. É um protótipo estático com carrinho e controle local de disponibilidade.

## Atenção
Os preços e produtos são ilustrativos. Não existe checkout real, banco de dados, autenticação ou pagamento ativo nesta versão. O painel é demonstrativo e não deve ser usado em produção.
